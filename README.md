# zenn-articles

Zenn（@oosawak）へのGitHub連携用リポジトリです。

- `articles/` — Zennに同期される記事のMarkdown。正本は Techブログ（oosawak.github.io の content/posts/tech/）で、こちらはZenn版として変換したもの。
- `images/` — 記事で使う画像。Zennの記法（`/images/ファイル名`）で参照しています（元画像はWebP、Zenn向けにJPEGへ変換済み）。

このリポジトリをZennの「GitHub連携」に設定すると、`main` ブランチへのpushがそのままZennへデプロイされます。
